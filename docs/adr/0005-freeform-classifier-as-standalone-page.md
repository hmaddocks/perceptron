# Freeform classifier added as a standalone page, not a third shared View

Unlike Table/Plane (ADR-0004), the freeform continuous-point classifier (ported from the original prototype Variant A) is a genuinely different domain — arbitrary labeled points on a continuous plane, not the fixed 4-row gate truth table — so folding it in as a third shared-state View would have meant either forcing an unrelated data model into the gate's perceptron state, or silently ignoring the shared state for one specific view. We instead gave it its own HTML page (`freeform.html`) with its own script/CSS files (`freeform-*.js`, `freeform.css`) and its own independent `Perceptron` instance, linked from the main page via a plain `<a>` rather than the view-menu tabs. The cost is a full page reload when navigating between them and no state continuity — acceptable since the two demos were never meant to share weights.
