# No-build vanilla JS/HTML/CSS instead of a framework

This is a live presentation tool that needs to run reliably on a presenter's laptop, possibly offline or on unfamiliar hardware, with the perceptron logic itself as legible as possible. We chose plain HTML/CSS/JS with no bundler or framework over React/Vite, trading away component ergonomics for zero install/build risk and a direct, unobstructed view of the actual perceptron code (no framework boilerplate between the reader and the math).
